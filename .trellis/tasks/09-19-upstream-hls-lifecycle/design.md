# 设计

在现有定制分支上创建集成分支并合并固定上游，保留两边历史。Ent 从合并 schema 重新生成。前端子模块单独合并，保留播放器与视频对话框。

永久删除复用文件树遍历和现有事务，提交后执行收集的 HLS 目录清理；持久失败由已有孤儿清理兜底，不提前删除仍被数据库引用的目录。回收站使用目录祖先链确认正常根，避免只检查记录存在。

HLS 授权复用现有文件管理器能力和分享校验。读状态要求有文件读取权限，删除仅文件所有者；公开播放通过显式签名/分享授权，不因 ID 可猜测而公开。播放列表与片段绑定文件及当前产物版本，时效使用现有 entity URL TTL；回收站即时拒绝新请求。

不把未使用的 Go 大版本带入项目。升级只在 1.26 系列。现有配置覆盖前备份 .bak/2026-09-19；Git 提交保留合并前历史。回滚需同步二进制、前端和数据库备份；本任务不操作生产。
