# 上游合并与 HLS 生命周期修复

## 授权与范围
用户明确授权 Trellis 覆盖升级、新任务、完成上游合并、修复本轮 HLS 问题、升级 Go 1.26 最新补丁。不开子代理，不推送、不部署。

## 需求与验收
- 保留字幕、批量视频处理、远程 FFmpeg、HLS 分享、队列 FIFO 和下载恢复功能。
- 合并官方后端 4.19.1（a8becb9f）及对应前端 19da0fe1；实际远端刷新后核对固定基线。
- Go 1.26.8 为本次官方确认的 1.26 最新稳定补丁，模块、Docker、CI 一致。
- 文件/批量/文件夹/清空回收站永久删除后，HLS 数据、空间与磁盘一致；失败清理可重试，不在事务回滚前误删文件。
- 移入回收站保留 HLS 数据但禁止播放（含祖先文件夹被回收）；恢复后可继续访问。
- HLS 状态/删除须正确权限；分享播放须有可过期可撤销凭据，片段不能绕过授权。页面播放器与分享入口保持可用。
- 片段编号六位及以上可播放，目录仍按文件 ID 和生成时间隔离。
- 后端完整测试、相关 race、前端类型检查/测试/构建通过，明确未执行的生产验证。
